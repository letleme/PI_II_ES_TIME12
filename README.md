## Sobre o Projeto

O projeto consiste no desenvolvimento de um **Sistema de Acompanhamento de Demandas de Desenvolvimento**, voltado para a organização e o acompanhamento de tarefas, defeitos, melhorias e atividades de documentação relacionadas a projetos de software.

O sistema permitirá o gerenciamento de demandas, possibilitando seu cadastro, visualização, edição, atualização de status e cancelamento, além do acompanhamento de responsáveis, prioridades, prazos, comentários e histórico de alterações.

O projeto será desenvolvido integrando **frontend, backend e banco de dados**, utilizando as tecnologias e requisitos definidos para o Projeto Integrador II.
